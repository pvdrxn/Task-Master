# 📝 Task Master

**Task Master** es una aplicación web desarrollada con Django que permite crear, organizar y gestionar tareas de forma eficiente. Diseñada como parte de mi portfolio profesional, este proyecto demuestra habilidades en desarrollo backend con Python/Django, diseño frontend accesible y estructuración de proyectos escalables.

---

## 🚀 Características principales

- ✅ Crear, editar y eliminar tareas
- 📌 Marcar tareas como completadas o pendientes
- 📅 Organización por fecha y prioridad
- 🔍 Filtros dinámicos para visualizar tareas activas, completadas o vencidas
- 🧑‍💻 Interfaz intuitiva y responsive con HTML, CSS y Bootstrap

---

## 🛠️ Tecnologías utilizadas

- **Python 3**
- **Django**
- **HTML5 / CSS3 / Bootstrap**
- **SQLite3** (modo desarrollo)
- **JavaScript** (para interacciones dinámicas)
